* Hello!
--------------------------------------------------------------------------------------------------
* If you like classic NES games you once played in your childhood,
* You can play them again now and relive those memories.
-------------------------------------------------------------------------------------------------
* If you are on windows run the mesen.exe in the windows folder.
* If you are on linux run the mesen in the linux folder.
--------------------------------------------------------------------------------------------------
* When you open the mesen application just press ctrl + o (to select the NES rom you want to play.)
* There are about 10,000 roms inside the topa folder you can play with (don't judge a folder by it's name :) )
* Just go to topa folder and search for your game.
